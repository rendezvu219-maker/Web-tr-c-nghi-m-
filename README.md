# Bài tập nhóm · Hồ sơ khai phá

Quiz độc lập theo chủ đề Honkai: Star Rail với 12 câu hỏi. Kết quả dựa trên lựa chọn của người chơi và hiển thị tiêu đề, ảnh vùng đất trong game cùng phần giải thích. Nếu điểm cao nhất hòa, trang hiển thị hồ sơ cân bằng và ảnh ghép bốn vùng đất.

## Thành viên nhóm

- Trần Nguyễn Phi Vũ — MSSV 22050102
- Phạm Hoàng Hùng — MSSV 22050033

- Mở `index.html` trong trình duyệt.
- `css/style.css`: giao diện riêng của bài nhóm.
- `js/quiz.js`: câu hỏi, tính điểm và tạo kết quả.
- `js/ui.js`: menu responsive với icon Morphicons.
- `images/`: ảnh Trạm Không Gian Herta, Jarilo-VI, Xianzhou Luofu và Penacony.

Trang tĩnh, có thể mở trực tiếp `index.html` hoặc host bằng GitHub Pages; không cần tự chạy server. jQuery 3.3.1 và Morphicons được tải từ CDN, nên cần Internet để tải thư viện. Giao diện dùng bảng màu be, đen và xanh lá nhạt.
